# tesla-key

Statische Seite für `https://tesla.eder.ac` (GitHub Pages).

- `/.well-known/appspecific/com.tesla.3p.public-key.pem`: öffentlicher Schlüssel für die Tesla Fleet API. Muss dauerhaft erreichbar bleiben.
- `/callback`: Zielseite für den OAuth-Login (zeigt die Adresse zum Kopieren).

Der private Schlüssel liegt nicht hier.
